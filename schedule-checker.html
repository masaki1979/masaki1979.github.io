Schedule Checker (personal)

Operated by masaki1979 · Effective date: October 4, 2026

Schedule Checker uses YouTube API Services. It is an independent personal tool and is not affiliated with, endorsed by, or sponsored by Google or YouTube.

This is a separate tool from Personal Video Scheduler, with its own Google Cloud project. The Personal Video Scheduler privacy policy does not cover this tool; this page does.

What this tool is

Schedule Checker is a small read-only program that runs only on the operator's own computer. The operator (masaki1979) uses it together with the posting tool the operator used before Personal Video Scheduler, to check which dates already have a scheduled or published video on the operator's own YouTube channel, so that two videos are not scheduled on the same day. It is for personal use only, is not offered to the public, and is not used to access anyone else's channel or data. It only reads; it never uploads, changes, or deletes anything on YouTube.

Privacy Policy

  • Use of YouTube API Services: the tool uses YouTube API Services with only the https://www.googleapis.com/auth/youtube.readonly permission. Information obtained through YouTube API Services is also subject to the Google Privacy Policy (http://www.google.com/policies/privacy).
  • Information it reads: the authorized channel's basic information and the ID of its list of uploaded videos, and, for the channel's recent videos, YouTube's standard information sets "snippet", "status", and "contentDetails". The tool uses only each video's title, publish or scheduled time, privacy status, and length (to tell Shorts from long-form videos). The other items in these sets (such as descriptions, tags, and thumbnail addresses) are discarded immediately.
  • How it is used: only to show the operator which dates are already taken. The free date that results is used by the operator's posting tool to schedule the operator's own next video. Titles, video IDs, and other information obtained from YouTube API Services are not sent anywhere and are not shared with, sold to, or rented to any third party. No third party can serve content or advertisements through the tool or collect information from its users. The tool uses no advertising, analytics, tracking, or cookies.
  • What it stores and where: only a token file in the operator's user folder on the operator's own computer, containing the refresh token, the granted permission, and the date of authorization. The lists of videos it reads are shown on the screen and are not stored, so no information obtained from YouTube API Services is kept.
  • How to revoke access: at any time from your Google Account: https://myaccount.google.com/connections or the Google security settings page https://security.google.com/settings/security/permissions. After access is revoked, the stored token no longer works; it is replaced when the operator authorizes the tool again, and the operator deletes it if the tool is no longer used.
  • Deletion requests and contact: email masaki.1979ai@gmail.com. Stored information is deleted within 7 days of a request. Deleting data stored by the tool does not affect any data stored by YouTube.

  • 読み取る情報：許可されたチャンネルの基本情報とアップロード動画の一覧の ID、そのチャンネルの最近の動画について YouTube が用意している標準の情報のまとまり「snippet」「status」「contentDetails」。使うのは各動画のタイトル、公開日時または公開予定時刻、公開状態、長さ（ショートと通常の動画を見分けるため）だけで、まとまりに含まれるほかの項目（説明、タグ、サムネイルのアドレスなど）はすぐに捨てます。
  • 使い道：どの日がすでに埋まっているかを運営者に示すためだけに使います。その結果わかった空いている日は、運営者の投稿ツールが運営者自身の次の動画を予約するのに使います。タイトル、動画 ID など YouTube API Services から得た情報はどこにも送らず、第三者に共有・販売・貸与しません。このツールを通じて第三者にコンテンツや広告を配信させたり、利用者から情報を集めさせたりすることはありません。広告、解析、トラッキング、Cookie は使いません。

  • 削除の依頼と連絡先：masaki.1979ai@gmail.com へのメールで依頼でき、7 日以内に削除します。ツールが保存したデータを削除しても、YouTube に保存されているデータには影響しません。
