Privacy Policy

Personal Video Scheduler · Effective date: October 3, 2026

Personal Video Scheduler uses YouTube API Services. By using this app, you are also subject to the Google Privacy Policy (http://www.google.com/policies/privacy).

Personal Video Scheduler is an independent personal tool and is not affiliated with, endorsed by, or sponsored by Google or YouTube.

1. About this policy

This Privacy Policy explains how Personal Video Scheduler (the "App") accesses, uses, stores, and shares information. The App is operated by masaki1979 (the "Operator"). It is a personal tool that runs on the Operator's own computer and is used by the Operator to schedule uploads of the Operator's own videos to YouTube channels that the Operator owns or manages. The App is not offered to the public.

2. Use of YouTube API Services

The App uses YouTube API Services to upload videos, set thumbnails, and read information about videos on the authorized channels. Information obtained through YouTube API Services is also handled by Google in accordance with the Google Privacy Policy.

3. Information the App accesses

  • OAuth tokens: the access token and refresh token that Google issues when the App is authorized for a channel. The App uses them only to call YouTube API Services for that channel.
  • Information about the authorized channel: the channel ID and channel name, used only to tell the Operator's channels apart and to confirm which channel a video will be uploaded to.
  • Information about the channel's videos: title, scheduled publish time, privacy status, and video ID of videos that are already scheduled or published. Although the youtube.readonly permission would allow reading other channel information, the App reads only this information.
  • Videos and metadata the Operator uploads: the video file, thumbnail image, and the settings entered by the Operator (title, description, tags, category, language, made-for-kids declaration, altered or synthetic content declaration, paid promotion declaration, and scheduled publish time).

The App does not access comments, subscribers, analytics, payment information, contacts, email, or any other Google service.

4. How the information is used

The information is used only to:

  • upload and schedule videos (including setting thumbnails and video settings), and
  • find a free date and time that is not already used by a scheduled or published video.

It is not used for any other purpose, such as advertising, profiling, or analytics.

5. Where the information is stored

  • All information is stored only on the Operator's own computer. The App has no server, and the Operator does not store the information in any cloud service.
  • OAuth tokens are stored in a file inside the Operator's user folder on that computer.
  • A local posting log (video ID and scheduled publish time of videos uploaded by the App) is kept on the same computer.
  • Information about the channel's videos is read from the API when needed to check for free time slots.

6. Sharing

  • The information is not shared with, sold to, or rented to any third party.
  • The App sends information only to Google / YouTube through YouTube API Services, for the purposes described above.
  • The App does not use advertising, analytics, tracking, or cookies.

7. Retention of API data

Data obtained from YouTube API Services (other than tokens needed to keep the App authorized) is not kept for more than 30 days without being refreshed. Any such data that the App stores, including the posting log, is deleted or refreshed with current data from the API within 30 days.

OAuth tokens are kept until access is revoked or the token file is deleted.

8. How to revoke access

You can revoke the App's access to your Google Account at any time:

  • Google Account, "Third-party apps & services": https://myaccount.google.com/connections
  • Google security settings page: https://security.google.com/settings/security/permissions

After access is revoked, the App can no longer read or upload anything for that account.

9. How to request deletion

You can ask for your stored information (for example, tokens and posting log entries related to your channel) to be deleted by sending an email to masaki.1979ai@gmail.com. The Operator will delete it within 7 days of receiving the request and will reply to confirm.

10. Security

Tokens and other stored information are kept only on the Operator's computer, inside the Operator's user folder, and are not published or sent anywhere other than to Google / YouTube.

11. Website

This website is hosted on GitHub Pages. The website itself uses no cookies, analytics, or tracking scripts. GitHub, as the hosting provider, may log technical information such as visitors' IP addresses; see the GitHub General Privacy Statement.

12. Changes to this policy

If this policy changes, the updated version will be posted on this page and the effective date above will be updated. Significant changes will be noted on this page.

13. Contact

Operator: masaki1979
Email: masaki.1979ai@gmail.com

プライバシーポリシー

Personal Video Scheduler（個人用の動画予約投稿ツール）・施行日：2026年10月3日

英語版と日本語版の内容は同じです。食い違いがある場合は英語版を優先します。

Personal Video Scheduler は YouTube API Services を使っています。このアプリを使う場合、Google プライバシーポリシー（http://www.google.com/policies/privacy）も適用されます。

Personal Video Scheduler は Google や YouTube とは無関係の個人のツールです。Google や YouTube が提供・承認・後援しているものではありません。

1. このポリシーについて

このプライバシーポリシーは、Personal Video Scheduler（以下「本アプリ」）が情報をどのように読み取り、使い、保存し、共有するかを説明するものです。本アプリは masaki1979（以下「運営者」）が運営しています。本アプリは運営者のパソコンの中で動く個人用のツールで、運営者が自分で作った動画を、自分が所有・管理する YouTube チャンネルに予約投稿するために使います。一般には公開していません。

2. YouTube API Services の利用

本アプリは YouTube API Services を使って、動画のアップロード、サムネイルの設定、許可されたチャンネルの動画の情報の読み取りを行います。YouTube API Services を通じて扱われる情報は、Google プライバシーポリシーにしたがって Google によっても取り扱われます。

3. 本アプリが読み取る情報

  • OAuth のトークン：チャンネルについて本アプリを許可したときに Google が発行するアクセストークンと更新用トークン。そのチャンネルについて YouTube API Services を呼び出すためだけに使います。
  • 許可されたチャンネルの情報：チャンネル ID とチャンネル名。運営者の複数のチャンネルを見分け、どのチャンネルにアップロードするかを確かめるためだけに使います。
  • チャンネルの動画の情報：予約済み・公開済みの動画のタイトル、公開予定時刻、公開状態、動画 ID。youtube.readonly の許可ではほかのチャンネル情報も読めますが、本アプリが読むのはこれらの情報だけです。
  • 運営者がアップロードする動画とメタデータ：動画ファイル、サムネイル画像、運営者が入力した設定（タイトル、説明、タグ、カテゴリー、言語、子ども向けの申告、改変または合成コンテンツの申告、有料プロモーションの申告、公開予定時刻）。

コメント、登録者、アナリティクス、支払い情報、連絡先、メール、そのほかの Google のサービスにはアクセスしません。

4. 情報の使い道

情報は次の目的だけに使います。

  • 動画のアップロードと予約公開（サムネイルや動画の設定を含む）
  • 予約済み・公開済みの動画と重ならない、空いている日時の判定

広告、プロファイリング、解析など、ほかの目的には使いません。

5. 情報の保存場所

  • 情報はすべて運営者のパソコンの中だけに保存します。本アプリにはサーバーがなく、運営者がクラウドサービスに保存することもありません。
  • OAuth のトークンは、そのパソコンの運営者のユーザーフォルダ内のファイルに保存します。
  • 投稿記録（本アプリでアップロードした動画の動画 ID と公開予定時刻）も同じパソコンの中に保存します。
  • チャンネルの動画の情報は、空いている日時を確認するときに、その都度 API から読み取ります。

6. 共有

  • 情報を第三者に共有・販売・貸与することはありません。
  • 本アプリが情報を送る先は、上記の目的のために YouTube API Services を通じて送る Google / YouTube だけです。
  • 広告、解析、トラッキング、Cookie は使いません。

7. API から得たデータの保存期間

YouTube API Services から得たデータ（本アプリの許可を保つために必要なトークンを除く）は、取り直さないまま 30 日を超えて保存しません。本アプリが保存するこうしたデータ（投稿記録を含む）は、30 日以内に削除するか、API から最新のデータを取り直して更新します。

OAuth のトークンは、許可が取り消されるか、トークンのファイルが削除されるまで保存します。

8. 許可の取り消し方

本アプリへの Google アカウントの許可は、次のページからいつでも取り消せます。

  • Google アカウントの「サードパーティ製のアプリとサービス」：https://myaccount.google.com/connections
  • Google のセキュリティ設定のページ：https://security.google.com/settings/security/permissions

許可を取り消すと、本アプリはそのアカウントについて読み取りもアップロードもできなくなります。

9. 削除の依頼方法

保存されている情報（たとえば、あなたのチャンネルに関するトークンや投稿記録）の削除は、masaki.1979ai@gmail.com へのメールで依頼できます。運営者は依頼を受け取ってから 7 日以内に削除し、削除したことを返信でお知らせします。

10. 安全管理

トークンなどの保存した情報は、運営者のパソコンのユーザーフォルダ内だけに置き、Google / YouTube 以外に公開したり送ったりしません。

11. このウェブサイトについて

このウェブサイトは GitHub Pages で公開しています。サイト自体は Cookie、解析、トラッキング用のスクリプトを使っていません。ホスティング事業者である GitHub が、閲覧者の IP アドレスなどの技術的な情報を記録することがあります。GitHub のプライバシーに関する声明をご覧ください。

12. ポリシーの変更

このポリシーを変更する場合は、このページに新しい内容を載せ、上の施行日を更新します。大きな変更がある場合は、このページでその旨をお知らせします。
